# Fresher disaster events + per-event details

## Why old events show up

The list is generated by the AI model from its own knowledge, and the request never tells it what today's date is or how to order results. So it falls back to whatever well-known events it remembers (2024 floods, etc.), in no particular order. Nothing in the app re-sorts them either.

## Fixes

1. Recency
   - Pass the current date into the request and explicitly ask for events from the last 12 months, most recent first, skipping anything older than ~2 years unless too few results exist.
   - Sort the returned list newest-first in the app before rendering, so ordering is guaranteed regardless of what the model returns.
   - Show a short note in the sheet that coverage depends on the model's knowledge and very recent events may be missing.

2. "More info" per event
   - Add a small circled "i" button on each event card.
   - Tapping it opens a compact detail panel with: what happened (2-3 sentences), number of people affected (killed / displaced / evacuated when known), the affected area figure, date, place, and source.
   - Unknown numbers are shown as "not reported" rather than invented.
